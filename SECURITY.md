# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/Pradyothsp/govec-python/security/advisories/new),
not as a public issue. If the issue is in the GoVec server rather than this client, report it
on [the server's repository](https://github.com/Pradyothsp/govec/security/advisories/new).

Include the SDK version (`pip show govec`), the server version (`client.info().version`), and
the steps to reproduce. The SDK is maintained by one person, so there is no guaranteed
response time, but reports are taken seriously and fixes are released as soon as practical.

## Supported versions

The SDK is pre-1.0. Security fixes go into the latest release only.
